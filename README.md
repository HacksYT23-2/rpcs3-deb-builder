# rpcs3-deb-builder

Unofficial script that repackages an RPCS3 AppImage into a .deb. Not affiliated with RPCS3.

## Usage
Download the AppImage from https://rpcs3.net, then:

    chmod +x make-rpcs3-deb.sh
    ./make-rpcs3-deb.sh ./rpcs3.AppImage 0.0.1

Set `ARCH=arm64` for the ARM build. This repo contains no RPCS3 binaries, PS3 firmware, or game files.
